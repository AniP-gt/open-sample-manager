## 使い方

アプリのSAMPLE画面で「Explore samples」を開きます。
「Back to library」で既存の一覧へ戻れます。

| 機能 | 実装した内容 |
|---|---|
| よく使う | 試聴・持ち出し・採用プロジェクト数を切り替え、過去30日／全期間・種類で絞り込み |
| プロジェクト | 既存コレクションの利用、新規作成、素材の追加・除外、候補／採用済み、素材ごとのメモ |
| 条件コレクション | 種類・再生タイプ・BPM上下限・お気に入り条件の保存、更新、呼び出し、削除 |
| 再発見 | 記録開始後の未試聴素材、90日以上操作記録のないお気に入り |
| A/B比較 | 2素材を比較枠へ登録し、同じ再生位置から切り替え。音量調整の有効／無効、停止 |
| 近い素材 | 同じ種類・再生タイプから、BPM・長さ・低域の割合・キーが近い順に表示 |

検索はSQLite内のライブラリ全体が対象で、100件ずつ追加表示します。
各素材はこの画面でも試聴・外部ドラッグ・プロジェクトへの追加ができます。
ライブラリで選択していた素材は、プロジェクトに直接追加できます。

## 記録と保存の意味

- 試聴はライブラリの実再生開始と、この画面の音声再生開始を記録します。
- 持ち出しはドラッグのドロップ完了を記録します。キャンセル時は加算しません。加工済みファイルも元素材に紐づけます。
- 同じ素材・同じ操作の5秒以内の繰り返しは1回にまとめます。
- 採用数は、現在「採用済み」のプロジェクトの数です。同じ棚への再追加やメモ保存で水増しされません。
- プロジェクトへの再追加では、既存の採用状態・メモを保持します。
- メモと採用状態の未保存入力は、画面を開いている間、別行の保存やタブ／プロジェクトの切り替えを挟んでも保持します。永続化には各行の「保存」を使います。
- 利用記録・プロジェクトの保存内容・条件コレクションはSQLiteに保存します。旧DBには起動時に追加テーブルを作成します。
- 利用履歴の集計はこのバージョンで記録を始めてからの範囲です。アプリ外の利用は集計しません。
- A/Bの音量調整はデコードした音声のRMS −20 dBFSを目標とし、ピークを−1 dBFS以下に制限します。聴感上の差が残る場合があります。
- 種類の選択肢は既存の標準9種類です。類似表示は解析済みメタデータの近さで並べます。
