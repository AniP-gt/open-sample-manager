# ランダム発見

ランダム発見では、ライブラリを変更したり新しいメタデータを書き込んだりせずに、音をすばやく試聴する三つの方法を追加します。

## Random

`Random` ボタンはサンプルリストのツールバーにあります。リストまたはグリッドに現在表示されている同じ結果セットから、一つのサンプルを選びます。

有効なフィルターはそのまま適用されます。

- 検索テキスト
- BPM 範囲
- サンプルタイプ
- 楽器タイプ
- 音楽キー
- お気に入りのみモード
- ディレクトリフィルター

複数の結果がある場合、`Random` は現在選択中のサンプルを避けます。選択行は手動クリックと同じ経路を通るため、最近使った項目、フォーカス、プレビュー再生の動作は一貫します。

## Back

`Back` ボタンは、現在のセッションで以前にランダム選択した項目をたどります。完全な取り消しではなく、すばやく試聴するための機能です。

ランダムに選んだ音が近かったものの、前の音の方が合っていた場合に使います。前の選択に戻れるランダム選択が少なくとも一つあるまで、ボタンは無効です。

## ランダムな類似サンプル

詳細パネルの `Find similar samples` の下には `Random similar sample` があります。

この操作は、選択中のサンプルに対して既存の埋め込み類似検索を実行し、使える一致をランダムに一つ選びます。類似サンプルモーダルは開かず、一致したサンプルを直接選択します。

ルールは次のとおりです。

- 別の類似結果が存在する場合、現在のサンプルは除外されます。
- ファイルパスがない結果は無視されます。
- 使える一致がない場合、アプリは `No similar samples found` を表示します。
- 選択中のサンプルにパスがない場合、アプリは `Sample path missing for embedding search` を表示します。

## 開発者向けの注記

サンプルリストのランダムフローは `SampleList` 内にあり、テストを再現可能にするために `randomSelection.ts` を使います。

`Random similar sample` は既存の `search_by_embedding` Tauri コマンドを再利用します。類似サンプルモーダルと同じヘルパーである `mapEmbeddingRowToSample` を通じて、埋め込み行をマッピングします。

データベーススキーマやバックエンドコマンドを変更する必要はありません。
