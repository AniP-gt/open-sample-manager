# 機能ドキュメント

Open Sample Manager は、オーディオサンプルと MIDI ファイルを閲覧、試聴、整理し、DAW へ移すためのローカルファーストのデスクトップアプリです。

アプリは現在、開発者向けプレビューです。ソースコードとして配布され、メタデータはローカルに保存されるため、アカウントやクラウドサービスは必要ありません。

- [MIDI ファイル管理](midi-file-management.md)
- [検索と整理](search-and-organization.md)
- [プレビュー同期とドラッグ書き出し](preview-sync-and-drag-export.md)
- [設定とローカルデータ](settings-and-local-data.md)

## ガイドの構成

これらのページは画面単位ではなくワークフロー単位で分けています。サンプルリスト、MIDI リスト、プレーヤーバー、サイドバー、設定パネル、プロジェクト同期コントロールは動作を共有するため、ワークフロー単位のページにすると検索、プレビュー、ローカルデータに関する同じ規則を繰り返さずに済みます。
