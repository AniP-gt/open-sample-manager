# プレビュー同期とドラッグ書き出し

Open Sample Manager は、音をプロジェクトへ移す前に試聴することを中心に作られています。

## プロジェクトコントロール

ヘッダーにはプロジェクト BPM とキーのコントロールがあります。サンプルと MIDI ファイルのプレビューにおける目標コンテキストとして使えます。

二つの同期オプションがプレビューの動作を制御します。

- テンポ同期は、目標 BPM に合わせて再生速度または MIDI テンポを調整します。
- キー同期は、目標キーに向けてサンプルをピッチシフトするか、MIDI ノートを移調します。

これらのコントロールは、アプリ内でのプレビューと書き出しの動作に影響します。ライブラリ内の元ファイルは編集しません。

## オーディオプレビュー

サンプルプレビューは、再生速度を変えてプロジェクト BPM に追従できます。キー同期が有効で、サンプルにキーのメタデータがある場合は、プレビューにピッチシフトも適用できます。

プレーヤーバーには、波形表示、ループ再生、選択時の自動再生、処理コントロールがあります。

## MIDI プレビュー

MIDI プレビューでは、TiMidity++ を通じた再生前にテンポを書き換え、ノートを移調できます。ドラムまたはパーカッションのチャンネル 9 は、移調中も変更されません。

## 元ファイルのドラッグ

サンプルと MIDI ファイルは、DAW を含む別の宛先へアプリからドラッグできます。元ファイルのドラッグでは、既存のファイルをソースとして使います。

## 加工済みサンプルのドラッグ書き出し

変更したオーディオファイルが必要な場合は、プレーヤーコントロールを開き、トリム、フェード、ゲインを設定します。アプリは元ファイルを変更せず、ドラッグ用に一時的な WAV をレンダリングします。

加工済みのドラッグ書き出しはオーディオサンプル専用です。MIDI のプレビュー同期は再生を変更しますが、ライブラリ内の保存済み MIDI ファイルは変更しません。
