# MIDI ファイル管理

Open Sample Manager は、オーディオサンプルと並べて MIDI ファイルを保存し、個別の閲覧、フィルター、タグ付け、再生機能を提供します。

## スキャン

MIDI スキャナーは、`mid` と `midi` の拡張子を持つファイルを再帰的に登録します。メタデータは解析され、サンプルライブラリと同じローカル SQLite データベースに保存されます。

## MIDI リスト

MIDI リストでは、ファイル名検索、ソート、ページネーション、お気に入り、選択、行アクションを使えます。行にはタグを表示でき、含まれるフォルダーを開く、ファイルパスをコピーする、ファイルをゴミ箱へ移動する、再生を開始する操作ができます。

## タグ

MIDI タグは作成してファイルに割り当てられます。タグは MIDI 検索に含まれるため、コードタイプ、グルーブ、ソースパック、楽器の役割、その他の任意のグループ分けに使えるカスタムラベルになります。

## 再生

MIDI 再生には TiMidity++ が必要です。アプリは一般的なプラットフォームのインストール場所とシステム `PATH` を確認し、MIDI ファイルをプレビューすると TiMidity++ を開始します。

新しい MIDI プレビューを開始すると、先に前の TiMidity++ プロセスを停止します。TiMidity++ がない場合は、設定パネルと README の設定セクションでインストール方法を説明します。

## プレビュー同期

MIDI プレビューは、プロジェクトの BPM とキーのコントロールに追従できます。再生前にテンポの書き換えとノートの移調が適用されます。パーカッションのチャンネル 9 は変更されないため、ドラムパートが音高のあるノートと同じように移調されることはありません。
