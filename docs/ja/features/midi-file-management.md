# MIDI ファイル管理

Open Sample Manager は、オーディオサンプルと並べて MIDI ファイルを保存し、個別の閲覧、フィルター、タグ付け、再生機能を提供します。

## スキャン

MIDI スキャナーは、`mid` と `midi` の拡張子を持つファイルを再帰的に登録します。メタデータは解析され、サンプルライブラリと同じローカル SQLite データベースに保存されます。

## MIDI リスト

MIDI リストでは、ファイル名検索、ソート、ページネーション、お気に入り、選択、行アクションを使えます。行にはタグを表示でき、含まれるフォルダーを開く、ファイルパスをコピーする、ファイルをゴミ箱へ移動する、再生を開始する操作ができます。

## フレーズ分類

MIDI ファイルのスキャン時には、ノートパターンも分類されます。ここで扱うのは再生音色ではなく、フレーズの動きです。

| 項目 | 値 | 判定に使う情報 |
|---|---|---|
| 役割 | `melody`、`chords`、`bass`、`drums`、`mixed` | 音域、ノートの重なり、パーカッションチャンネル |
| 発音構造 | `monophonic`、`polyphonic` | トラック内でノートが重なるか |
| 密度 | `sparse`、`medium`、`dense` | 1 小節あたりのノート数 |
| 音域 | `low`、`mid`、`high`、`wide` | 平均音高と音高の幅 |
| 小節数 | 数値 | MIDI ティックと拍子 |
| 楽器候補 | General MIDI の楽器ファミリー | Program Change またはパーカッションチャンネル |

MIDI リストでは、これらを `ROLE`、`TEXTURE`、`BARS`、`INSTRUMENT` 列に表示します。リスト上部のフィルターでは、役割、発音構造、密度、音域、代表的な小節数を組み合わせて絞り込めます。

役割は固定ルールで判定します。MIDI チャンネル 10 は、ファイル内部では 0 始まりのチャンネル 9 として扱われ、パーカッションに数えられます。音高のあるノートの平均が MIDI ノート 48 未満なら `bass`、同時に 3 音以上が鳴れば `chords` です。残りの音高フレーズは `melody`、音高フレーズとパーカッションの両方を含む場合は `mixed` になります。

密度は 1 小節あたり 4 音未満なら `sparse`、4 音以上 12 音未満なら `medium`、12 音以上なら `dense` です。音域は平均 MIDI ノートで判定しますが、最低音から最高音までが 36 半音以上の場合は `wide` になります。

楽器候補は再生音色の確定情報ではありません。Program Change がない MIDI、General MIDI 以外の音色マップを使う MIDI、外部シンセを制御する MIDI では、楽器候補が空欄になったり、DAW で聞こえる音と一致しなかったりします。

分類結果はスキャン時に保存されます。この機能を追加する前に登録した MIDI は、対象フォルダーを再スキャンするまで分類欄が空のままです。

## タグ

MIDI タグは作成してファイルに割り当てられます。タグは MIDI 検索に含まれるため、コードタイプ、グルーブ、ソースパック、楽器の役割、その他の任意のグループ分けに使えるカスタムラベルになります。

タグは手動ラベルです。フレーズ分類は MIDI イベントから自動生成され、カスタムタグを置き換えるものではありません。

## 再生

MIDI 再生には TiMidity++ が必要です。アプリは一般的なプラットフォームのインストール場所とシステム `PATH` を確認し、MIDI ファイルをプレビューすると TiMidity++ を開始します。

新しい MIDI プレビューを開始すると、先に前の TiMidity++ プロセスを停止します。TiMidity++ がない場合は、設定パネルと README の設定セクションでインストール方法を説明します。

## プレビュー同期

MIDI プレビューは、プロジェクトの BPM とキーのコントロールに追従できます。再生前にテンポの書き換えとノートの移調が適用されます。パーカッションのチャンネル 9 は変更されないため、ドラムパートが音高のあるノートと同じように移調されることはありません。
