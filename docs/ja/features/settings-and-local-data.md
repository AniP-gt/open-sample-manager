# 設定とローカルデータ

Open Sample Manager はローカルファーストです。ライブラリのメタデータは自分のマシンに保存され、クラウドアカウントは不要です。

## ローカルデータベース

デスクトップアプリは、プラットフォームのアプリデータディレクトリに `samples.db` SQLite データベースを作成します。データベースには、サンプルメタデータ、MIDI メタデータ、タグ、楽器ラベル、監視対象パス、スキャンのタイムスタンプ、解析結果が保存されます。

SQLite は WAL を有効にして動作します。アプリはファイル名検索用の FTS5 テーブルも保持します。

## 設定

設定パネルには次のコントロールがあります。

- サンプル選択時の自動再生
- 楽器の色分け
- ディレクトリクリックでのフィルター
- TiMidity++ の状態と案内
- データベースの書き出しと取り込み

お気に入りや最近使ったサンプルの履歴など、一部の UI 設定はフロントエンドによってローカルに保存されます。

## ライブラリの移行

設定から、ローカルのメタデータデータベースを `samples.db` として書き出し、別のマシンで取り込めます。

この書き出しはメタデータのみです。オーディオと MIDI のファイルはコピーされません。取り込んだメタデータが正しく解決されるのは、参照先のファイルが取り込み先のコンピューターに同じパスで存在する場合だけです。

データベースの取り込みでは、現在のデータベースを置き換える前にファイルを検証します。検証に失敗した場合、現在のデータベースは保持されます。

## リモートに保存されないもの

アプリは、ファイル、解析データ、タグ、お気に入り、設定をクラウドサービスへアップロードしません。ここで説明したすべてのデータは、アプリを実行しているマシン上にあります。
