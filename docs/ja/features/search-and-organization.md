# 検索と整理

アプリは、バックエンド検索、UI フィルター、お気に入り、最近使った項目の履歴、編集可能なラベルを組み合わせ、大きなローカルライブラリを閲覧しやすく保ちます。

## 検索

オーディオサンプル検索は、ファイル名とタグに対するあいまい検索です。空のクエリでは全リストが返ります。MIDI 検索は、ファイル名とタグテキストに対するあいまい検索です。

SQLite の FTS5 テーブルはサンプルと MIDI のファイル名用に維持されます。また UI は、高速な閲覧のためにリストレベルのあいまい一致とフィルターも適用します。

## フィルター

サンプルブラウザーでは、サンプルタイプ、楽器タイプ、BPM 範囲、キー、お気に入り、ディレクトリでフィルターできます。MIDI ブラウザーでは、ファイル名、キー、テンポ、タグ、お気に入りでフィルターできます。

ディレクトリフィルターは設定で有効にできます。有効にすると、サイドバーのフォルダーをクリックしたときに、現在のライブラリ表示がそのフォルダーに絞り込まれます。

## お気に入りと最近使ったサンプル

オーディオサンプルと MIDI ファイルには、それぞれ独立したお気に入り状態があります。お気に入りはローカルに保存され、絞り込んだ閲覧フィルターとして使えます。

サイドバーには最近使ったサンプルのリストもあります。最近使った項目を選ぶと、もう一度検索せずにそのサンプルへ戻れます。

## 分類の編集

自動解析は常に正しいとは限りません。アプリからサンプルの再生タイプと楽器タイプを上書きできます。

楽器ラベルはユーザーが編集できます。カスタム楽器タイプは SQLite に保存され、追加、名前変更、削除ができます。

## ファイル操作

行には、一般的なライブラリ作業のためのファイル単位の操作があります。

- 含まれるフォルダーを開く
- ファイルパスをコピーする
- ファイルをゴミ箱へ移動する
- 別のアプリへファイルをドラッグする

ゴミ箱と一時ファイルのクリーンアップはデスクトップシェル層で保護されるため、アプリは意図したファイル操作だけを通じてファイルを削除します。
