# オーディオサンプル管理

Open Sample Manager は、オーディオサンプルのフォルダーをスキャンして解析し、結果をローカルライブラリに保存できます。

## スキャン

アプリは一般的なオーディオサンプルファイルをフォルダーから再帰的にスキャンします。スキャナーは `wav`、`mp3`、`flac`、`ogg`、`aiff` の拡張子を受け付けます。再スキャン中は、すでにライブラリにあるパスをスキップするため、新しいファイルに集中できます。

Rust コアがファイルを解析してメタデータを SQLite に書き込む間、スキャンの進行状況がアプリへ通知されます。

## 解析

取り込んだサンプルは解析用にモノラル音声へデコードされます。アプリは、閲覧と試聴に役立つメタデータを保存します。

- BPM 推定
- 音楽キー推定
- キック検出
- ループまたはワンショット分類
- 波形ピーク
- 類似性検索用の埋め込みデータ

この解析は、大きなサンプルフォルダーを検索しやすくするためのものです。自動結果が音に合わない場合は、UI から分類を修正できます。

## サンプルリスト

サンプルリストは、ページネーション、ソート、選択、行アクションを備えた密度の高いデスクトップテーブルです。より視覚的に閲覧したい場合は、グリッド表示も使えます。

各サンプル行から、ファイルをお気に入りに追加する、含まれるフォルダーを開く、パスをコピーする、ゴミ箱へ移動する、別のアプリへドラッグする操作ができます。

## 波形プレビュー

サンプルを選択すると、プレーヤー領域に再生コントロールと波形プレビューが表示されます。プレーヤーでは、選択時の自動再生、ループ再生、加工済みバージョンのサンプルをドラッグしたい場合の処理コントロールを使えます。

## 類似サンプル

類似性検索は、選択したサンプルの保存済み埋め込みを、ローカルデータベース内の他の埋め込みと比較します。保存済みデータに対する総当たりのコサイン検索であり、リモートサービスやインデックス済みサービスではありません。類似性検索は、選択したサンプルに有効な埋め込みがある場合だけ使えます。
