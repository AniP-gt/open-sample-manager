# Feature Documentation

Open Sample Manager is a local-first desktop app for browsing, previewing, organizing, and moving audio samples and MIDI files into a DAW.

The app is currently a developer preview. It is distributed as source code, stores metadata locally, and doesn't require an account or cloud service.

## How The Guides Are Split

These pages are split by workflow instead of by screen. The sample list, MIDI list, player bar, sidebar, settings panel, and project sync controls share behavior, so workflow-based pages avoid repeating the same search, preview, and local data rules.
